## Verification

Passed (observed):

- Sign in → root restores last board; Boards ▾ → Create board works; title pill with `···` (Board settings) and Boards ▾ present; `Board settings` opens rename/delete.
- Repositories → `alice/project` → State All → Connect repository: Incoming completes 3 pages automatically, 5 rows, focus moves to the "Incoming 5" heading.
- Filter: query "Issue 5" → 1 row; state Open → 2 rows; heading count follows matches, trigger count stays at queue length.
- Add all matching: 5 cards placed, `.tl-shapes` transform unchanged, Incoming panel stays open, announcement "5 cards added.", focus on the Incoming heading, save state `saved`.
- Undo button in the footer: 0 cards, Incoming 5, "Addition undone."; Ctrl+Z / Ctrl+Shift+Z: 0→5 cards and queue 5→0 (run 1).
- Find → result → card selected, centred, Card details shows the full 430-character title; Escape closes details and focus returns to the canvas; the card's "1 related items" button opens details.
- Native resize by corner drag: 280x200 → 460x360, full title visible (scrollHeight = clientHeight), persisted after reload. Dragging a card by its title moves it without text selection.
- View → Project Delivery auto-maps Status/Estimate/Priority/Iteration; Weight 0 renders "0" on Issue #1; Connections All draws 2 dashed curves; details lists "Related 3"; selection persists after reload (project P_alice, connections `all`).
- Light and dark: every measured text pair ≥ 5.57:1 except the dark placeholder (3.41:1); input border 3.67:1 light / 4.44:1 dark; related curve 7.08:1 / 9.74:1.
- Keyboard: every stop has a visible ring (2-3px solid accent); Incoming/Find/View/Details close on Escape and return focus to their trigger.
- Back/Forward: rectangle drawn on board B then immediate Back (save state `unsaved` at that moment) → board A shown with 5 cards; Forward → B with the shape; reload → shape persisted (guard flushed the save). Account link → `/account`, Back → board with canvas.
- No horizontal document scroll at 320px or 640px (`scrollWidth` = viewport). No `pageerror`; console errors were only the fixture 502s.
- No custom transitions or animations declared outside tldraw.

Not verified:

- RTL mirroring, forced-colors mode, screen-reader announcement timing of the `role=status` regions, reduced-motion behaviour of tldraw's own animations, Safari/iOS input zoom.
- Item-URL lookup in Repository search (added after the review started), Sources route, conflict/recovery overlays, live GitHub.
- The old E2E suite (per the brief, not reviewed).

## Verdict

**Block** - five HIGH findings remain: Find is unclickable over most of its surface while Incoming is open; the focused skip link is fully hidden; Add all matching is covered at 320px and clipped at 200% zoom; dark-theme placeholder text fails 4.5:1. Not reviewed: RTL, forced-colors, screen-reader runtime, Sources route, recovery/conflict overlays.
